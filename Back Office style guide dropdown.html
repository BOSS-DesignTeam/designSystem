Dropdown

A bare wa-dropdown shell — you author your own trigger and boss-dropdown-item content, including arbitrary custom markup per item.

standardexperimental

When to use

Reach for boss-dropdown when you need a trigger-driven menu whose items are more than plain text — icons, multi-line rows, badges, anything a boss-dropdown-item can hold. The component only owns the wa-dropdown shell and its positioning; you supply the trigger (with slot="trigger") and every boss-dropdown-item yourself.

Don't use it for a simple primary-action-plus-variants menu with plain string options — orderly-split-button already covers that case more concisely.

Known limitation: wrapping items in boss-dropdown-item disables arrow-key navigation between them (click/tap still work). See "Dropdown Item" below for details.

#Interactive content

Form with a combobox

A form doesn't belong inside a wa-dropdown-item — its click-to-select-and-close behavior would fire on every click inside the combobox. Put it in a plain div instead; wa-dropdown ignores non-wa-dropdown-item content for selection and keyboard navigation, so the dropdown stays open while the form is used. Call the dropdown's close() method (via a template reference) once the form's own action completes.

#Dropdown Item

boss-dropdown-item is a thin wrapper around wa-dropdown-item — it's the element you put inside a boss-dropdown for anything that should act as a selectable menu entry (as opposed to a plain div, which wa-dropdown ignores for selection and keyboard navigation — see "Interactive content" above).

Known limitation:wa-dropdown finds its menu items by checking each slotted child's tag name directly, so wrapping wa-dropdown-item in any Angular component — including this one — hides it from that check. Click-to-select, auto-close, and the disabled/variant styling below all work normally, but arrow-key navigation between items does not. This only affects keyboard users cycling through the menu with arrow keys; mouse and touch interaction are unaffected.

Variants and state

variant='danger' styles a destructive action; disabled greys the item out and blocks click/select.
